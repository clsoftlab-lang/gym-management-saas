## 소개

짐매니저는 운동 서비스업을 하나의 웹앱으로 운영하는 통합 플랫폼입니다. 빌드가 필요 없는 정적 사이트(순수 HTML + CSS + ES 모듈 JS)라서 GitHub Pages에 그대로 올라갑니다.

## 기능 (데모 모드에서 실제 동작)

- **대시보드** — 핵심 지표 카드(전체/이용중 회원, 오늘 출석, 이번 달 매출, 만료 임박) + 차트 3종: 월별 매출(막대), 이용권 구성(도넛), 14일 출석 추이(라인).
- **회원 관리** — 실시간 **검색**(이름/전화/ID), **필터**(상태·이용권), **정렬 가능한 컬럼**, 등록/수정/삭제, 회원 상세(출석·결제·락커·PT), 이용권 연장·재등록, 일시정지/재개, 원클릭 체크인.
- **출석 체크인** — 이름으로 빠르게 찾아 체크인, 오늘 출석 명단, 출석률.
- **수업·예약** — 요일별 주간 시간표, 정원/예약 현황 바, 그룹수업·PT 예약/취소, 강사진.
- **락커 관리** — 구역별 락커 맵, 이용중 회원 배정/반납, 가동률 통계.
- **결제·매출** — 필터 가능한 결제 내역, 월별 매출 차트, CSV 내보내기.
- **리마인더·알림** — 만료 임박(7·30일) 회원에게 **모의** 문자 템플릿과 발송 표시.
- **회원용 화면** — 내 이용권/D-day, 내 예약, 셀프 체크인, 수업 예약, PT·락커 현황(데모 계정 전환).
- **저장** — 모든 편집은 `localStorage`에 저장, **"데모 데이터 초기화"** 버튼으로 시드 복원.
- **UX** — 모바일 우선 반응형, `prefers-color-scheme` 기반 라이트/다크, 한국어 UI, 토스트·모달.

## 로컬 실행

```bash
# 저장소 루트에서
python -m http.server 8000
# 브라우저에서 열기:
#   http://localhost:8000/
```

정적 서버라면 무엇이든 동작합니다(반드시 http://로 서빙해야 하며, `index.html`을 `file://`로 열면 JSON 시드 `fetch`가 차단됩니다).

## 검증

```bash
node check.mjs
```

`data/*.json` 파싱, 모든 `.js`/`.mjs`의 `node --check`, `index.html` 필수 요소를 확인합니다. CI가 푸시마다 동일 검사를 실행합니다(`.github/workflows/ci.yml`).

## 🟨 데모 모드 경계 (반드시 확인)

**본 앱은 시연용 데모이며, 운영 시스템이 아닙니다.**

- **데모/시드 데이터 전용.** 모든 회원·전화번호·결제·스케줄은 **가상**이며 데모용으로 생성되었습니다. **실존 인물 없음, 실제 개인정보(PII) 없음.**
- **`localStorage`는 실제 DB가 아닙니다.** 데이터는 해당 브라우저에만 존재하고, 기기·사용자 간 공유되지 않으며 언제든 삭제될 수 있습니다.
- **실제 결제 없음.** 매출·결제 수치는 가짜이며 실제 청구는 발생하지 않습니다.
- **실제 문자/알림 없음.** 리마인더 "발송"은 UI 모의이며 브라우저 밖으로 나가지 않습니다.
- **계정/인증 없음.** 회원용 화면의 계정 전환은 데모 편의 기능이며 로그인이 아닙니다.
- **실서비스에는 추가로 필요:** 백엔드 + 데이터베이스, 인증·인가, 실제 결제(PG) 연동, 실제 SMS/알림톡 게이트웨이, 그리고 **개인정보 처리 및 개인정보보호법(PIPA) 준수**.

## 기술 스택

- 빌드 없는 정적 SPA: `index.html` + `styles.css` + ES 모듈 JS(`app.js`, `js/*`).
- 차트는 [Chart.js](https://www.chartjs.org/) CDN(cdn.jsdelivr.net), 그 외 전부 인라인/로컬.
- 시드 데이터는 `data/*.json`, 해시 기반 라우터, `localStorage` 저장(try/catch 래핑).
- 상대 경로만 사용하여 GitHub Pages 서브경로에서도 동작.
