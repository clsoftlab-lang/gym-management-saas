## 소개

짐매니저는 운동 서비스업을 하나의 웹앱으로 운영하는 통합 플랫폼입니다. 빌드가 필요 없는 정적 사이트(순수 HTML + CSS + ES 모듈 JS)라서 GitHub Pages에 그대로 올라갑니다.

## 기능 (데모 모드에서 실제 동작)

- **대시보드** — 핵심 지표 카드(전체/이용중 회원, 오늘 출석, 이번 달 매출, 만료 임박) + 차트 3종: 월별 매출(막대), 이용권 구성(도넛), 14일 출석 추이(라인).
- **회원 관리** — 실시간 **검색**(이름/전화/ID), **필터**(상태·이용권), **정렬 가능한 컬럼**, 등록/수정/삭제, 회원 상세(출석·결제·락커·PT), 이용권 연장·재등록, 일시정지/재개, 원클릭 체크인.
- **출석 체크인** — 이름으로 빠르게 찾아 체크인, 오늘 출석 명단, 출석률.
- **수업·예약** — 요일별 주간 시간표, 정원/예약 현황 바, 그룹수업·PT 예약/취소, 강사진.
- **락커 관리** — 구역별 락커 맵, 이용중 회원 배정/반납, 가동률 통계.
- **결제·매출** — 필터 가능한 결제 내역, 월별 매출 차트, CSV 내보내기.
- **리마인더·알림** — 만료 임박(7·30일) 회원에게 **모의** 문자 템플릿과 발송 표시.
- **회원용 화면** — 내 이용권/D-day, 내 예약, 셀프 체크인, 수업 예약, PT·락커 현황(데모 계정 전환).
- **저장** — 모든 편집은 `localStorage`에 저장, **"데모 데이터 초기화"** 버튼으로 시드 복원.
- **UX** — 모바일 우선 반응형, `prefers-color-scheme` 기반 라이트/다크, 한국어 UI, 토스트·모달.

## 🤖 AI 기능 (API 연동)

앱에는 세 가지 AI 기능이 내장되어 있습니다(메뉴: **AI 어시스턴트 / 🤖**).

1. **AI 트레이너 코치 챗봇** — 회원·매니저가 운동/식단/이용권/예약을 자연어로 물으면 실용적인 한국어 답변을 제공합니다(선택한 회원의 이용권·PT 잔여·최근 출석을 반영한 개인화 가능).
2. **이탈 위험 회원 요약 + 맞춤 리텐션 메시지** — 만료 임박·출석 저조 회원을 골라 이탈 위험을 요약하고, 개인화된 재등록 유도 문자(SMS) 초안을 작성합니다.
3. **공지/문자 문구 자동 작성** — 한 줄 브리핑을 공지·안내 문구와 문자 축약본으로 만들어 줍니다(채널·톤 반영).

**라이브 데모는 내장 목업(mock) 프로바이더**(`ai/ai.js` → `MockProvider`)로 동작합니다. 앱의 실제 회원·출석 데이터를 재사용해 결정적(deterministic) 한국어 결과를 생성하므로 **백엔드도 API 키도 필요 없이** GitHub Pages에서 그대로 동작합니다. 목업 출력은 "데모 AI"임을 명확히 표시합니다.

**실제 AI를 사용하려면**, [`server/`](server/README.md)의 참조 프록시를 **운영자 본인의** `ANTHROPIC_API_KEY`로 배포하고(저비용 기본 모델 **`claude-haiku-4-5`**, 변경 가능, 스트리밍), [`ai/config.js`](ai/config.js)의 `AI_ENDPOINT`를 그 프록시의 `/api/ai` URL로 설정하면 됩니다. 그러면 브라우저가 프록시로부터 응답을 스트리밍합니다.

> **API 키는 서버에만 두며, 브라우저·저장소에는 절대 넣지 않습니다.** `ai/config.js`에는 키가 아니라 프록시 주소만 들어가고, 키는 서버의 `process.env.ANTHROPIC_API_KEY`에서 읽습니다. `check.mjs`는 `AI_ENDPOINT` 기본값이 비어 있는지와, 저장소 어디에도 실제 API 키 문자열이 없는지를 검증합니다.

## ⚙️ 고도화 — 무인·저비용 실 AI 연동

AI 레이어는 **무인(autonomous) · 실제 AI 연결(real Claude) · 비용 합리적(cost-efficient)** 운영에 맞춰 고도화되어 있습니다.

- **비용 모델 — 기본 `claude-haiku-4-5` ($1/$5 per MTok) + 프롬프트 캐싱 + 토큰 상한.**
  `AI_MODEL`로 변경 가능(`claude-sonnet-5`·`claude-opus-5`로 상향). 고정 시스템 프롬프트를
  캐시 블록(`cache_control:{type:'ephemeral'}`)으로 보내 반복 호출의 입력 비용을 크게 낮추고,
  출력은 `AI_MAX_TOKENS`(기본 700)로 제한합니다. Haiku는 thinking/effort를 보내지 않고(모델이
  거부), 그 외 모델은 adaptive thinking + `output_config.effort`(기본 `low`)를 사용합니다.
- **대략적 비용:** Haiku 4.5 기준 **1,000요청당 약 $2**(요청당 출력 ~400토큰, 캐싱 적용).
  Sonnet 5 ≈ 2배, Opus 5 ≈ 5배. 월 토큰 예산(`AI_MONTHLY_TOKEN_CAP`, 기본 2,000,000)과
  IP당 레이트 리밋으로 비용을 방어하며, 초과 시 프록시가 `429 {fallback:true}`를 반환합니다.
- **무인 (무료 Cloudflare Workers 배포):** [`server/worker.js`](server/worker.js) + [`server/wrangler.toml`](server/wrangler.toml)를
  Cloudflare **무료 티어**(`wrangler deploy`)로 올리면 **관리할 서버가 없습니다.** Node용
  [`server/index.mjs`](server/index.mjs)도 그대로 제공됩니다. 자세한 내용은 [`server/README.md`](server/README.md).
- **절대 멈추지 않음 (자동 목업 폴백):** 엔드포인트 호출 실패 / 429 / 네트워크 오류 시
  `ai/ai.js`가 **내장 목업으로 자동 폴백**하여 무인 상태에서도 앱이 계속 동작합니다.
- **자율 기능 — 오늘의 운영 브리핑:** 대시보드가 로드 시 앱 자체 집계 엔진 + `askAI`로 운영
  브리핑(오늘 만료임박 · 이탈위험 · 매출 요약)을 자동 생성합니다. 오프라인(목업)에서도 동작합니다.

> **API 키는 서버에만 둡니다 — 브라우저·저장소에는 절대 넣지 않습니다.** Node 서버는
> `process.env.ANTHROPIC_API_KEY`, Worker는 Cloudflare **시크릿**에서 키를 읽습니다. `check.mjs`는
> 저장소 전체에서 실제 `sk-ant-…` 키를 스캔해, 커밋되면 실패시킵니다.

## 로컬 실행

```bash
# 저장소 루트에서
python -m http.server 8000
# 브라우저에서 열기:
#   http://localhost:8000/
```

정적 서버라면 무엇이든 동작합니다(반드시 http://로 서빙해야 하며, `index.html`을 `file://`로 열면 JSON 시드 `fetch`가 차단됩니다).

## 검증

```bash
node check.mjs
```

`data/*.json` 파싱, 모든 `.js`/`.mjs`의 `node --check`, `index.html` 필수 요소를 확인합니다. CI가 푸시마다 동일 검사를 실행합니다(`.github/workflows/ci.yml`).

## 🟨 데모 모드 경계 (반드시 확인)

**본 앱은 시연용 데모이며, 운영 시스템이 아닙니다.**

- **데모/시드 데이터 전용.** 모든 회원·전화번호·결제·스케줄은 **가상**이며 데모용으로 생성되었습니다. **실존 인물 없음, 실제 개인정보(PII) 없음.**
- **`localStorage`는 실제 DB가 아닙니다.** 데이터는 해당 브라우저에만 존재하고, 기기·사용자 간 공유되지 않으며 언제든 삭제될 수 있습니다.
- **실제 결제 없음.** 매출·결제 수치는 가짜이며 실제 청구는 발생하지 않습니다.
- **실제 문자/알림 없음.** 리마인더 "발송"은 UI 모의이며 브라우저 밖으로 나가지 않습니다.
- **계정/인증 없음.** 회원용 화면의 계정 전환은 데모 편의 기능이며 로그인이 아닙니다.
- **실서비스에는 추가로 필요:** 백엔드 + 데이터베이스, 인증·인가, 실제 결제(PG) 연동, 실제 SMS/알림톡 게이트웨이, 그리고 **개인정보 처리 및 개인정보보호법(PIPA) 준수**.

## 기술 스택

- 빌드 없는 정적 SPA: `index.html` + `styles.css` + ES 모듈 JS(`app.js`, `js/*`).
- 차트는 [Chart.js](https://www.chartjs.org/) CDN(cdn.jsdelivr.net), 그 외 전부 인라인/로컬.
- 시드 데이터는 `data/*.json`, 해시 기반 라우터, `localStorage` 저장(try/catch 래핑).
- 상대 경로만 사용하여 GitHub Pages 서브경로에서도 동작.
